# 总览（2026-09-29）

本计划含 5 项任务，文件地图与使用约定见 [`README.md`](./README.md)。本文件只写总览：质量口径、任务概览、顺序与依赖、关键决策、调研方法、验收与回滚、风险。

## 质量口径（把口号翻译成可验收行为）

| 口号 | 本任务集的可验收含义 |
|---|---|
| 高质量 | 依赖方向仍单向（`models ← utils/core/gui`）；写入口唯一（数据写 `CardModel`，绘制走 `_draw_card`）；无函数体中部 `import`；错误统一走 `utils/error_handler.py` |
| 高稳定 | 环境状态（文件是否存在、网络是否可达、磁盘是否可写）不参与数据合法性判断；任何环境失败都可降级且不中断主流程；配置读写可往返（存 → 读 → 语义不变） |
| 高可用 | 网络/磁盘失败静默降级；长任务不进 GUI 线程；关窗不 `terminate`（沿用上一轮口径）；UI 在任何失败下仍可继续操作 |
| 高扩展 | 新增能力只加薄层：新异步任务照抄 `utils/thread_manager.py` 既有范式，新偏好只加字段，新菜单项只加动作；不引入模板 DSL、不换工具链 |

## 顺序与依赖

`01 → 02 → 03 → 04 → 05`。

- `01` 是唯一"整份产物不可用"级缺陷，且它改的是**配置读写边界**；后四项都在这条边界上工作。
- `02` 最小，只新增偏好字段，先做可验证偏好读写链路（含测试夹具）。
- `03` 触碰全部数据变更入口，放在偏好改动收敛之后。
- `04` 独立，但引入本项目第一次主动外呼，需单独评审隐私与失败口径。
- `05` 是发布动作，必须最后做（打包含前四项）。

无硬依赖是可并行项；按上序执行可让每次提交的范围与条目一一对应。

## 关键决策（已定，附理由）

| # | 决策 | 理由 |
|---|---|---|
| D1 | 校验器只校验**数据**，不校验环境（去掉 `Path.exists()`） | 环境状态是运行期事实；放进校验器会让"数据合法性"与"环境可用性"耦合，实测后果是整份配置打不开。渲染侧本就有降级路径 |
| D2 | 相对路径以**配置文件所在目录**为基准；跨盘回退绝对路径 | Python 官方文档明确：`os.path.relpath` 与 `pathlib.Path.relative_to` 在 Windows 跨盘时抛 `ValueError`，必须显式回退 |
| D3 | 撤销采用**状态快照 + `QUndoStack` 容器**，不为每种变更写命令类 | `CardModel` 每次变更都整份重建 `EnemyData`。一条命令保存前后两份快照；`push()` 调用 `redo()` 完成写入。栈提供 `canUndo`/`canRedo` 与 `setUndoLimit`。评价标准名称在应用偏好中，保存标准后清空栈 |
| D4 | 版本检查**默认开启、可关闭、24h 冷却、不自更新** | 官方限流按 IP 计且匿名 304 也消耗配额；自更新需签名与替换运行中进程，风险与工程量远超收益 |
| D5 | 打包继续用 **PyInstaller onedir**，不换 Nuitka / `pyside6-deploy` | `pyside6-deploy` 是 Nuitka 包装，Qt 官方部署文档承认它同样可能拉入未使用的 Qt 大模块；库依赖多时 onedir 体积 PyInstaller 更优 |
| D6 | 体积收敛只删除确认未使用的重模块；不维护 QML 或 DLL 白名单 | PyInstaller 无法跟踪 QML import，钩子会收整棵 `qml`，`excludes` 拦不住连带 DLL。`QtQuick/Controls` 整棵保留。`QtQuick` 里只删导入表或 `qmldir` 证明在引用已删模块的插件目录。`Qt6ShaderTools` 与 `opengl32sw` 不删。删完后若保留文件仍引用被删 DLL，构建失败 |

## 调研方法

- **内部**：全仓锚点核对（`file:line`），覆盖入口、编排、桥接、模型、线程、偏好、测试、打包配置与产物实测（`du`）。
- **外部**：官方文档优先（Qt 6、PyInstaller、Pydantic、Python、GitHub REST、SemVer），社区结论仅作补充；每条给出 URL。
- **实测**：本机 `.venv` 内 PyInstaller hook 源码、`dist` 产物内容、`du -sh` 体积。
- 已知方法学限制：一次并行外部调研中有 3 路子任务卡死被取消，其覆盖范围已由本地 hook 源码实测与自建检索补齐；结论中区分「官方文档事实」与「工程判断」。

## 风险总览

| 风险 | 影响 | 处置 |
|---|---|---|
| 删除 Qt 二进制导致启动即崩 | 产物不可用 | `05` 采用逐批实测（每批重新构建并跑三件事），先排除最确定的大项 |
| 校验放宽后放行垃圾路径 | 卡片显示占位而非报错 | 以 toast 一次性提示 + 日志 warning 补足可观测性 |
| 撤销栈内存增长 | 长时间编辑占用上升 | `setUndoLimit` 限深 + 压栈时深拷贝的文档体积很小 |
| 更新检查触发限流或泄漏隐私 | 提示失灵 / 隐私顾虑 | 24h 冷却 + 静默失败 + 只带 `User-Agent` + 可关闭 |
| 偏好文件新增字段与旧文件不兼容 | 旧偏好读取失败 | Pydantic 字段默认值 + 既有容错读源（缺失/损坏按默认值处理） |
